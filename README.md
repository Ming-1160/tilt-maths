# 乘除滾滾球（Tilt Maths）

小學乘除法滾球遊戲的網頁試玩版。這是大學「流動應用程式設計」科小組 App 的原型；正式版會用 MIT App Inventor 製作（Android）。

**試玩：** https://ming-1160.github.io/tilt-maths/

## 玩法

- 題目例如「12 ÷ 4 = ?」。木板四個角各有一個洞，洞旁有一個答案。
- 傾斜手機（先按「用手機傾斜」），或按住木板的一邊，令小球滾進答案的洞；小球停在洞上約 0.5 秒才算選擇。
- 每輪 10 題，完場列出最常見的錯誤類型。

## 設計重點

- **錯誤選項來自常見錯誤**：12 ÷ 4 的 8、16、48 分別代表做了減法、加法、乘法；4 × 3 的 7、15 或 9、43 分別代表當成加法、多算或少算一組、把兩個數字拼在一起。
- **答題後動畫解說**：除法（等分除）把長方形用線平均分成幾份，方塊一個一個輪流放進每一份；乘法一組一組出現並跳數。
- **設定**：除法／乘法／混合；入門（因數 2–5）／進階（因數 2–9）；不限時。
