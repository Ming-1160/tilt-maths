# 乘除滾滾球（Tilt Maths）

小學乘除法滾球遊戲的網頁試玩版。這是大學「流動應用程式設計」科小組 App 的原型；正式版會用 MIT App Inventor 製作（Android）。

**試玩：** https://ming-1160.github.io/tilt-maths/

## 玩法

- 題目例如「12 ÷ 4 = ?」。木板上有四個洞，洞旁有答案。
- **傾斜模式**：先按「用手機傾斜」，傾斜手機令小球滾進答案的洞；小球停在洞上約 0.5 秒會選取答案，再按「確認答案」才計分。
- **按鈕模式**：直接按四個答案按鈕，給不方便傾斜或手機沒有感應器的學生。
- 題型：除法、乘法、混合；入門（2–5）／進階（2–9）。每輪十題，同一輪不重複。
- 完場總結：星星數、用了多少次提示、圖意判斷答對多少題；可以再玩一輪。
- **派糖遊戲**：在主畫面按「派糖」，把寫有數字的糖包拖進籃子，令每籃一樣多。分得不平均會提示；可以返回上一步或重新開始；成功會灑彩紙，第一次就成功會顯示「一次成功」；除法之後再答一條四選一。

## 設計重點

- **傾斜只選取，按確認才計分**，避免手震誤交。
- **公平選項**：正確答案的位置經過平衡，學生不能靠「揀最細」之類的方法估中。
- **中性回饋**：說明數字關係，例如「8 是 12 − 4 的結果」，不會斷定學生為甚麼錯。
- **答題後動畫解說**：除法把物件逐個平均分到空籃；乘法一組一組出現並跳數；可以重播。動畫後問一條圖意小題，例如「12 ÷ 4 = 3 中，4 代表甚麼？」。
- **自選提示**：學生自己按「提示」，最多三級，全部用圖，不直接給答案；連錯兩題時提示按鈕會閃。
- 不用 AI、不設帳戶、不收集資料。
